# Форма — демонстрация для GitHub Pages

Это готовые статические файлы. Устанавливать Node.js и собирать проект не нужно.

## Публикация по HTTPS

1. Распакуйте ZIP.
2. Создайте репозиторий GitHub. На бесплатном плане для Pages обычно используется публичный репозиторий.
3. Загрузите **содержимое** архива в корень репозитория: `index.html` должен находиться рядом с `assets/`. Не загружайте только ZIP и не оставляйте сайт внутри лишней папки.
4. Откройте **Settings → Pages → Build and deployment → Source → Deploy from a branch**.
5. Выберите **main** и **/(root)**, нажмите **Save**.
6. Готовый адрес GitHub покажет в разделе Pages. Для адреса `github.io` HTTPS включается автоматически; при наличии настройки оставьте **Enforce HTTPS** включённой.

Официально: [публикация из ветки](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site), [HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https).

## Возможности этой сборки

Работают главная, категории и каталог, локальная корзина с выбором сохранения, поиск 1 126 городов и регионов, варианты получения, карта по разрешению и просмотр проектов документов. Пути подходят как для корня домена, так и для подпапки репозитория.

**Регистрация, вход, отправка заказов, история и административные изменения здесь не выполняются.** GitHub Pages не запускает серверную часть. На соответствующих страницах показано объяснение; успешная отправка не имитируется. Для полной версии используйте отдельный архив исходников и подходящий сервер/аутентификацию.

Товары, контакты и цены демонстрационные, документы — проекты. Этот архив предназначен для просмотра прототипа, а не для приёма реальных заказов и платежей. Платформа Pages получает технический IP посетителя; документы нужно привести к фактической инфраструктуре перед коммерческим запуском.

## Файлы

- HTML в корне — страницы; `assets/` — CSS, JS, изображения и шрифт.
- `assets/pages-adapter.js` — локальные публичные данные каталога и справочника; он не хранит заказы и не подделывает аутентификацию.
- `.nojekyll` — публикация файлов без обработки Jekyll.
- `CITY-DATA-SOURCES.md` и `CITY-DATA-LICENSE.txt` — источник и лицензия справочника. Источники фото и шрифта находятся в их папках.

Проверены синтаксис, локальные пути и сценарии DOM на адресах с подпапкой и без неё. Реальный Safari и публикация в вашем GitHub не выполнялись.
